# Contributing to CHat-app

Welcome! Thank you for considering contributing to the CHat-app project. We appreciate your help in improving our application.

## How to Contribute

1. **Fork the repository**: Use the 'Fork' button to create your own copy of the repo.
2. **Clone your fork**: Download your version of the repo to your local machine.
   ```bash
   git clone https://github.com/your-username/CHat-app.git
   cd CHat-app
   ```
3. **Create a branch**: Before making any changes, create a new branch. Name it appropriately based on the feature or issue you're working on.
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**: Edit the files as necessary. Be sure to keep your changes focused and organized.
5. **Commit your changes**: After making changes, save and commit them with a descriptive message.
   ```bash
   git add .
   git commit -m "Add your descriptive message here"
   ```
6. **Push to your fork**: Push your changes back to your fork of the repository.
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Create a Pull Request**: Go to the original repository and create a new Pull Request. Explain your changes and why they are necessary.

## Code of Conduct

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.

## Questions?

If you have any questions or need clarification on how to contribute, feel free to reach out.

Thank you for your contributions!
